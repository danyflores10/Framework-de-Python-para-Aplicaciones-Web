JSON · HTTP

API REST de cursos

Servicio web que intercambia datos en formato JSON y aplica los verbos HTTP GET, POST, PUT y DELETE mencionados en el video. Comparte las mismas validaciones que los formularios HTML.

Endpoints disponibles

Método Ruta Descripción Códigos HTTP
GET /cursos Endpoint original del video: código, nombre y créditos ordenados por nombre. 200, 503
GET /api/cursos Lista completa. Filtros opcionales: q, modalidad, orden y dir. 200
GET /api/cursos/<codigo> Obtiene un curso por su código. 200, 404
POST /api/cursos Crea un curso a partir de un cuerpo JSON. 201, 400, 409, 422
PUT /api/cursos/<codigo> Reemplaza los datos de un curso (el código no cambia). 200, 400, 404, 422
DELETE /api/cursos/<codigo> Elimina un curso. 200, 404
GET /api/estadisticas Total de cursos, créditos y distribución por modalidad. 200
