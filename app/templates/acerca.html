Arquitectura del proyecto (MVC)

  • Modelo: app/modelos/curso.py y app/database.py, con las consultas SQL a PostgreSQL, MySQL o SQLite.
  • Vista: plantillas Jinja2 de app/templates y recursos de app/static.
  • Controlador: blueprints de app/rutas: principal, cursos y api.
  • Configuración: app/config.py y variables del archivo .env.
  • Pruebas: carpeta tests con pytest y el cliente de pruebas de Flask.
